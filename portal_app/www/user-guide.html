ATA Project Portal — User Guide

Everything you need to run projects, manage the document tree, and share files safely with your team and your clients.

Read time ~15 min No login needed to read this page Print-friendly

What this portal is

A single place for every project, every document, and every person working on it.

Everything already lives in your main ERP system. The portal is just a simpler, faster screen for the things you do every day — opening a project, finding a drawing, sending a folder to a client — without needing to learn the full ERP.

Three things it does that matter most:
  • It builds your folders for you. Every new project gets the same complete folder tree automatically. Nobody has to remember the structure.
  • It keeps documents private. Files are stored privately by default. Only people with access to the project can open them.
  • It gives clients their own door. A client logs in and sees only their own projects — nothing else, ever.

Signing in

  1. Open the portalGo to /portal-app on your company address. Bookmark it.
  2. Enter your email and passwordUse the work email your administrator registered. If you have never set a password, use the link in your welcome email.
  3. You land on your home screenManagers see the Dashboard first. Everyone else goes straight to Projects.
Signing out properly Click your name in the top-right corner and choose Logout. This properly ends your session — not just on your screen. Closing the tab is not the same thing. Always do this on a shared or client machine.

Where your login comes from

Accounts are created for you — you cannot sign yourself up. How you get yours depends on who you are:

You areHow you get your account
ATA staff Your system administrator creates it and adds you to your projects. You receive a welcome email with a link to set your own password.
A client contact Your project manager at ATA invites you from your project. You receive a welcome email and choose your own password from the link inside it.

If you forget your password

  1. Click "Forgot password" on the login pageEnter the email address your account uses.
  2. Check your inboxA reset link arrives within a few minutes. Look in your spam folder if it does not.
  3. Set a new passwordThe link opens a page where you choose it yourself.

If no email arrives, contact your system administrator — the address on your account may be different from the one you are checking.

Your login is yours alone Never share your password, and never sign in on someone else's behalf. Everything done in the portal — every upload, every share, every deletion — is recorded against the account that did it. If you need someone to have access, ask an administrator to give them their own account; it takes a minute.

Who can see what

The portal looks different depending on your role. This is the single most useful table in this guide.

Two points people often misread
  • A Projects Manager sees every project, not only their own. What is restricted for them is the money — they only see the value of projects where they are named as Portal Project Manager.
  • A Projects User cannot edit, even on a project they lead. They have full read access and can upload files, but cannot change project details or delete anything. This is deliberate.

Adding a customer

Every project belongs to a customer. Add the customer first, or create it while creating the project.

  1. Go to ProjectsClick Projects in the left menu, then New Project.
  2. Start typing in the Customer boxStart typing and it looks for matches.
  3. If they do not exist, create themChoose the create option and type the full company name. Type the name exactly as it should appear on paperwork, because this is what the client sees.
Get the name right the first timeThe customer name links the client's own login to their projects. Renaming later is possible but means checking that client logins still point at the right company.

Adding your team to a project

This is the step that lets a colleague see the project at all. Miss it and the project simply will not appear for them.

  1. Open the projectProjects → click the project name.
  2. Find the team sectionAdd people one at a time, or add a whole User Group at once.
  3. SaveThey can see it straight away. They do not need to log out and back in.
Removing someoneTake them off the team and their access disappears straight away, including to the files.

The folder structure

Every project gets the same 67-folder tree, built automatically the moment the project is created.

You never have to create this by hand, and you should not change the standard folders. Consistency is the point — anyone can open any project and know exactly where a title deed or a permit lives.

Adding your own folderYou can add extra sub-folders inside the standard ones for a specific project. Use a number prefix (e.g. 07-SITE SURVEY) so it sorts correctly. Folder names cannot contain a slash.
Changing the template for all future projectsOnly a user with the Auditor role can do this, under File tools. It affects every project created afterwards, so it is treated as a governance setting.

Uploading files

  1. Go to FilesLeft menu → Files. Pick your project at the top.
  2. Click into the folder you wantThis matters. The file goes where you are standing. Navigate all the way down to the right sub-folder first.
  3. Choose your filesDrag and drop, or click to browse. You can select several at once.
  4. Check the confirmation boxThe portal suggests a file type based on the extension (a .dwg becomes AutoCAD). Change it if it guessed wrong.
  5. ConfirmThe files appear in the folder straight away.
Some file types are refused Web and program files — .html, .svg, .js, .exe, .bat and similar — cannot be uploaded. They can carry code that runs in someone's browser. Put them in a .zip if you genuinely need to store one.

Private vs public files

Understand this one setting and you will not accidentally publish a client's documents.

SettingWho can open the fileUse it for
Private Default Only people with access to the project, and anyone holding a valid share link Everything. Drawings, title deeds, IDs, permits, contracts.
Public Anyone at all who has the web address — no login needed Almost nothing. Only material you would be happy to see published.
The Private tick box is on by default — leave it on Unticking it puts the document on the open internet for anyone who knows or guesses the file name. There is no way to know afterwards who downloaded it. If you are not certain, leave it ticked; share links work perfectly well with private files.

ZIP upload & bulk download

Uploading a ZIP

Drop a .zip in and the portal unpacks it, recreating the folders inside it underneath wherever you are standing. Useful for moving an existing project archive in one go.

  • Up to 2,000 files and 500 MB unpacked per archive.
  • Hidden files and Mac system files are skipped automatically.
  • If the ZIP has a single wrapper folder, it is stripped so you do not end up with a pointless extra level.

Downloading several files at once

  1. Tick the files you wantUse the checkboxes in the file list.
  2. Choose "Download selected as ZIP"
  3. The archive downloadsFolder structure is preserved inside it.
LimitsUp to 500 files or 500 MB per download. For more than that, take it folder by folder.

Routing rules (automatic filing)

Rules that copy or move a file automatically based on where it was uploaded.

Example: everything dropped into 06-SITE PICTURE should also appear in 04-DRAWINGS. Set that once as a rule and it happens on every upload, in every project, without anyone remembering.

  1. Files → Routing rulesAuditor role required.
  2. Create a ruleGive it a clear name.
  3. Set the sourceThe folder to watch, and how to match it — contains, starts with, or exact.
  4. Set the targetWhere the file should also go.
  5. Pick the typeCross-route files it elsewhere; Mirror keeps a copy in both.
  6. Tick Enabled and saveUntick Enabled at any time to pause it without deleting it.
Test on one project firstUpload a throwaway file and check it lands where you expect before relying on a new rule.

Sharing a folder with a colleague

  1. Open Files and navigate to the folder
  2. Choose SharePick the person and set how many days the access should last.
  3. They find it under "Shared"In their left menu. They get read access to that folder and everything under it.
You can only share with people entitled to the projectThe portal will refuse if you pick someone from a different client, or someone with no portal access. This is deliberate.

Share links (for people without a login)

A web address you can email to someone outside the system.

  1. Open the folder and choose "Create share link"
  2. Set an expiryBetween 1 and 365 days. Keep it short.
  3. Copy the link and send itAnyone with the link can view and download the files in that folder — no login needed.
Treat a share link like a key Anyone the link is forwarded to can open it. It cannot be traced back to one person. Use the shortest sensible expiry, and revoke it when the client has what they need.
Links are tamper-proofEach link is digitally signed. Editing the address by hand breaks it, and it is refused.

Revoking access

  1. Go to Files → SharesEvery share you can manage is listed here.
  2. Find the share and click Revoke
  3. It stops working immediatelyThe next time anyone opens that link they get "revoked or expired". There is no delay and no cache to wait out.
Expiry is automatic tooShares past their expiry date are switched off by the system every hour, so nothing is left open by accident.

Inviting a client

Give your client their own login that shows only their own projects.

  1. Open one of that client's projectsThe project must already have the Customer field filled in.
  2. Find the client access sectionAdd a new client user with their email and full name.
  3. They receive a welcome emailThey set their own password from the link. You never choose a password on their behalf.
  4. DoneThey can now sign in at /portal-app and see their projects.
One client contact, one companyA client login is tied to a single customer. If the same person represents two companies they need two logins.
Internal staff cannot be made client contactsThe portal refuses to link a colleague's account to a customer. Doing so would strip their staff access and lock them to one client.

  1. Left menu → TasksFilter by project, status, priority, or search.
  2. Create a taskGive it a subject, pick the project, set priority and a due date.
  3. Assign itChoose a team member. It appears in their list.
  4. Discuss itOpen the task and add comments — a running record everyone on the project can read.

Daily Task board

Your own private to-do list — a four-week board of personal reminders.

These are yours alone. Nobody else sees them, not even your manager. They are separate from project Tasks, which are shared work items.

  • Add a reminder with a title, a time and a colour.
  • Tick it off when done.
  • Managers can create a reminder for a team member; it then belongs to that person.

Teams & Org Chart

Teams are departments. Each has an office (Riyadh, Manila, Lisbon and so on) and a list of members.

  • Teams — see each team, its office, its members and how many projects it is carrying.
  • Org Chart — the same information drawn as a company structure.
  • Add or remove members from a team, one person at a time or a whole User Group at once.
Managers onlyThese two screens are for System Managers and Projects Managers. They contain staff contact details, so other roles do not see them.

Dashboard

The manager home screen: project and task counts, budget health, sales this month, top projects by revenue, team size, and recent activity.

Money figures follow the roles tableA Projects Manager sees value figures only for the projects they manage, so two managers can legitimately see different totals on the same screen.

Common questions

I cannot see a project I know exists.

If you are a Projects User, you only see projects you have been added to as a team member. Ask the project manager to add you. If you are a client contact, you only ever see your own company's projects.

Why can I see the project but not its value?

Project value is restricted. System Managers see all values. A Projects Manager sees the value only for projects where they are named as Portal Project Manager. Everyone else sees none.

I am a Projects Manager but cannot make myself manager of a project.

Correct — that field controls who can see the project's money, so only a System Manager can move it. Ask one to make the change.

My upload was refused.

Most likely the file type. Web and program files such as .html, .svg, .js and .exe are blocked because they can run code in a browser. Put the file in a .zip if you must store it. Client contacts cannot upload at all.

The file went into the wrong folder.

Files land in the folder you are currently viewing. Navigate all the way into the correct sub-folder before uploading. If a routing rule is enabled it may also place a copy elsewhere by design — check Routing rules.

A client says a share link stopped working.

It has expired or been revoked. Check Files → Shares. You can extend a share you created, or issue a new link.

Should I ever untick "Private upload"?

Almost never. A public file can be downloaded by anyone on the internet who knows the address, with no login and no record of who took it. Share links work fine with private files — use those instead.

Can two people work on the same project at once?

Yes. Uploads, tasks and comments from different people appear as they happen. Refresh if you are waiting on something a colleague is doing.

If something goes wrong

  1. Refresh the pageMost one-off glitches clear.
  2. Sign out and back inFixes anything caused by a permission change made while you were logged in.
  3. Try a private browser windowThis rules out an old cached copy of the portal.
  4. Report it with detailYour administrator needs four things: what you were doing, which project or file, the exact message, and roughly what time. The time matters most — it lets them find the matching entry in the system log.
