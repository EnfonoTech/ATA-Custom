ATA Project Portal — Handbook

Your projects, your drawings and your client documents in one place, with the folder structure built for you every time. This is the short guide to using it well.

What the portal is

A simpler front door to the ERP, built around how ATA actually works.

Everything already lives in the ERP system. The portal gives you a faster screen for the things you do every day — opening a project, finding a drawing, sending a folder to a client — without having to learn the full ERP.

It does this for youSo that
Builds the folder tree automaticallyEvery project has the same structure. Nobody has to remember it, and nobody invents their own.
Keeps documents private by defaultA title deed or an ID is only readable by people with access to that project.
Gives each client their own doorA client logs in and sees only their own projects. Never another client's.
Records who did whatEvery upload, share and deletion is attributed to a named person.

Two things people read wrongly
  • A Projects Manager sees every project, not only their own. What is restricted for them is the money — they see the value only of projects where they are named as Portal Project Manager.
  • A Projects User cannot edit, even on a project they lead. They can read everything on their projects and upload files, but not change project details or delete. That is deliberate.
Everyone at ATA currently starts as a Projects User All 66 staff were loaded with the most restricted role on purpose. Nobody is a Projects Manager until you decide who should be — because that role reveals the whole portfolio. Ask your administrator to raise individuals from the Admin screen.

Signing in

  1. Go to the portalOpen /portal-app on the company address and bookmark it.
  2. Use your work emailYour account is already created. If you have never set a password, use Forgot Password? and one will be emailed to you.
  3. You land on your home screenManagers see the Dashboard. Everyone else goes straight to Projects.
Signing out properly Click your name, top right, then Logout. That ends the session on the server, not just on your screen. Always do this on a shared or client machine.

Dashboard

The manager home screen: how many projects and tasks are open, budget health, and recent activity.

Projects

Creating a project

  1. Projects → New Project
  2. Fill in the detailsName and customer are the important ones. The project number goes in Project code.
  3. SaveThe full folder tree is built at this moment — you never create folders by hand.
Only a System Manager can change the Portal Project Manager Because that field controls who can see the money, a Projects Manager cannot move it to themselves. Ask a System Manager if it needs changing.

The folder system

Every project gets the same 67-folder tree, built automatically the moment it is created.

This is the heart of the portal. You never build it by hand, and you should not change the standard folders — consistency is the whole point. Anyone can open any project and know exactly where a title deed or a permit lives.

Adding a folder of your own You can add extra sub-folders inside the standard ones for a particular project. Start the name with a number — 07-SITE SURVEY — so it sorts properly. Folder names cannot contain a slash.

Adding files

  1. Open Files and pick your project
  2. Click all the way into the right folderThis matters — the file lands where you are standing, not at the top.
  3. Drag your files in, or click to browseSeveral at once is fine, and a whole ZIP will be unpacked with its folders intact.
  4. Check the confirmation box and confirmThe portal guesses the file type from the extension; correct it if it guessed wrong.
Private vs public — the one setting to understand Private means only people with access to the project can open the file. Public means anyone at all with the web address can download it, with no login and no record of who took it. Leave it private. Share links work perfectly well with private files, so there is almost never a reason to untick it.
Some file types are refused Web and program files — .html, .svg, .js, .exe — cannot be uploaded, because they can run code in someone's browser. Put one inside a .zip if you genuinely need to store it.

Finding a file

Sharing

With a colleague

Open the folder, choose Share, pick the person and set how many days. They will find it under Shared in their own menu.

With someone who has no login

Create a share link. Anyone holding the link can view and download that folder — no login needed.

Treat a share link like a key Anyone it is forwarded to can open it, and you cannot tell who. Use a short expiry, and revoke it under Files → Shares once the client has what they need. Revoking takes effect immediately.

House rules

  1. One login per person, never sharedEvery upload, share and deletion is recorded against the account that did it. A shared login destroys that trail.
  2. Leave uploads privatePublic means anyone on the internet with the address. Use a share link instead.
  3. Navigate into the right folder before uploadingThe file lands where you are standing.
  4. Short expiries on share links, and revoke when doneUnder Files → Shares.
  5. Do not change the standard foldersTheir sameness across every project is what makes them useful.

Questions

I cannot see a project I know exists.

If you are a Projects User you only see projects you have been added to. Ask the project manager to add you. A client contact only ever sees their own company's projects.

Why can I see the project but not its value?

Project value is restricted. System Managers see all values; a Projects Manager sees only projects where they are the named Portal Project Manager; everyone else sees none.

My upload was refused.

Most likely the file type — web and program files are blocked. Client contacts cannot upload at all.

The file went into the wrong folder.

Files land in the folder you are viewing. Navigate all the way in before uploading. A routing rule may also place a copy elsewhere by design.

A client says a share link stopped working.

It expired or was revoked. Check Files → Shares — you can extend a share you created, or issue a new link.

Getting help

  1. Refresh the pageClears most one-off glitches.
  2. Sign out and back inFixes anything caused by a permission change made while you were logged in.
  3. Report it with detailYour administrator needs four things: what you were doing, which project or file, the exact message, and roughly what time. The time matters most.
