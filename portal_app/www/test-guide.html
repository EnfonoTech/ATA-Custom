6Area 6 — Sharing files and folders, share links, and revocation11 tests

This area covers every way a file or folder leaves the hands of the person who uploaded it: handing a colleague read access to a project folder, handing them one single file, and creating a public link that anyone can open without logging in. It matters because these are the only features in the portal that let an outsider read project documents, so the checks that stop the wrong person getting in — a faked link, a link that was cancelled, a contact from a different customer — have to work every time. How expiry works, in one sentence: every share is given an end date when it is created, the link itself carries that end date inside it so it is refused the moment it passes, and an automatic job runs every hour to switch off any share whose date has gone by.
